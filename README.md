Project Oveview
This project focuses on analyzing customer shopping behavior to understand purchasing patterns, customer preferences, sales performance, and business insights.
The project includes data cleaning, data analysis, SQl queries and an interactive Power BI dashboard.

Tools Used
. Python
. Pandas
. Numpy
. PostgreSQL
. Power BI
. Jupyter Notebook

Project files
. Customer shopping behavior csv
. Customer shopping behavior cleaned csv
. Python jupyter notebook
. SQL file
. Power BI dashboard
. Dashboard png

Project Workflow
. Data collection and understanding
. data cleaning using python and pandas
. Handling missing values and duplicates
. Exploratory Data Analysis (EDA)
. SQL- based data analysis
. Dashboard creation using power bi
. Business insights and visuallization

Key Objectives
. Understanding customer purchasing behavior
. Analyze sales and product performance
. Identify customer shopping patterns
. Generates meaningfull business insights
. Present findings through an interactive dashboard

Conclusion
This project demonstrates practical data analysis skills using Python, SQL, and Power BI to tranform raw shopping data into meaningfull business insights.
